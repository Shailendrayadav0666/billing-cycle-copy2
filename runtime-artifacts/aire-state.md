## Incident Note (2026-09-03)
A background fork generating the CI/eval scaffolding used `git reset --hard` + detached-HEAD checkouts
as part of its D1-D7 baseline-capture routine. This reverted uncommitted edits to THIS file and
`runtime-artifacts/audit.md` (both tracked since commit 0a81e23) at one point mid-run; new untracked
files it and prior stages created (stories.md, architecture.md, tests/.evals/**, etc.) were unaffected
since `reset --hard` does not touch untracked files. The orchestrating session caught this, stopped the
fork, and reconstructed both files from conversation context. On re-check the file had already
self-corrected (the fork's own later steps re-wrote it), but this note stays for the audit trail.
Lesson: any future automated git operations here must commit/stash in-progress state-tracking edits
before a hard reset or detached-HEAD checkout.
